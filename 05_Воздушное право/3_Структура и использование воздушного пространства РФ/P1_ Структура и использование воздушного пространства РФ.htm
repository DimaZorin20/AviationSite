Структура и использование воздушного пространства РФ

В воздушном пространстве над территорией Российской Федерации, а также за ее пределами, где ответственность за организацию воздушного движения возложена на Российскую Федерацию, устанавливаются:

  • класс A - в верхнем воздушном пространстве (выше эшелона полета FL265 (8100 м)), где предоставляется диспетчерское обслуживание воздушного движения или осуществляется управление полетами воздушных судов;
  • класс С - в нижнем воздушном пространстве (от эшелона полета FL265 (8100 м) и ниже), где предоставляется диспетчерское обслуживание воздушного движения или осуществляется управление полетами воздушных судов;
  • класс G - в воздушном пространстве, выше 150м AGL, где не устанавливаются классы А и С.
  • класс H - в воздушном пространстве, ниже 150м AGL, где не устанавливается класс С, а также в воздушном пространстве, выделенном для маршрутов полетов для беспилотных воздушных судов.

Класс A

В воздушном пространстве класса A выполнение полета по ПВП запрещено.

При выполнении полета по ППП:

  • предоставляется диспетчерское обслуживание - обслуживание, предоставляемое в целях:
    • предотвращения столкновений;
    • ускорения и регулирования воздушного движения;
  • диспетчер обеспечивает безопасные интервалы (эшелонирование) между всеми ВС;
  • отсутствуют ограничения по скорости;
  • необходима постоянная двусторонняя радиосвязь;
  • необходимо разрешение на использование воздушного пространства.

Класс C

При выполнении полета по ПВП:

  • предоставляется диспетчерское обслуживание;
  • диспетчер обеспечивает эшелонирование только относительно ВС, выполняющих полет по ППП;
    • Эшелонирование относительно ВС, выполняющих полет по ПВП, экипаж обеспечивает самостоятельно.
  • ниже FL100 максимальная скорость полета - 250 узлов;
  • необходима постоянная двусторонняя радиосвязь;
  • необходимо разрешение на использование воздушного пространства.
При выполнении полета по ППП условия аналогичны полету в классе А.

Класс G

При выполнении полета по ПВП и ППП:

  • предоставляется полетно-информационное обслуживание - обслуживание с целью предоставления консультаций и информации для обеспечения безопасного и эффективного выполнения полетов.
  • эшелонирование не предоставляется;
  • ниже FL100 максимальная скорость полета - 250 узлов;
  • для полета по ПВП постоянная двусторонняя радиосвязь не требуется;
  • необходимо уведомить диспетчеров об использовании воздушного пространства.

Класс H

В воздушном пространстве класса H выполнение полета по ППП запрещено.

При выполнении полета по ПВП:

  • предоставляется полетно-информационное обслуживание
  • эшелонирование не предоставляется;
  • Для всех полетов действует ограничение по скорости, составляющее не более 250 узлов
  • Для полета по ПВП постоянная двусторонняя радиосвязь не требуется;
  • Необходимо уведомить диспетчеров об использовании воздушного пространства.
